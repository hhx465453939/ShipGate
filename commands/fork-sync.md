# /fork-sync — 开源 Fork 分支同步管理器

当你在维护开源项目 fork 并需要同步上游更新时使用此命令。它会自动检测 ahead/behind 分歧，分析功能级冲突，引导你逐项决策（保留本地 vs 采用上游），在新版本上嵌入本地功能，测试后推送。

## 使用方式

```
/fork-sync
```

命令会自动检测当前仓库的 upstream 配置和分歧状态，按 5 个阶段执行：

1. **检测** — 展示 ahead/behind 详情
2. **分析** — 冲突预判矩阵
3. **合并** — 自动合并 + 逐冲突决策
4. **测试** — 完整测试验证
5. **推送** — 选择推送方式和 PR 策略
